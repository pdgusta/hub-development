# Perguntas do Gustavo (rodada 5 do ticket 56), sementes

1. Se o Gustavo editar um arquivo do context hub (no Obsidian ou direto no disco), o que acontece?
2. Se um agente novo iniciar a sessão no context hub, o que acontece?
3. Se um maestro novo iniciar a sessão no context hub, o que acontece?
4. Se o Gustavo pede a um agente uma leitura, alteração ou remoção de arquivo, o que acontece?
5. Se o outro par altera um arquivo, o que acontece?

Outros tipos citados por ele: "qual a relação entre X e Y?", "quem é responsável por X?", "X faz parte do grupo lógico
de Y?".
