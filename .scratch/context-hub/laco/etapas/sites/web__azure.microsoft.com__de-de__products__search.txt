 01/ 

Was ist Azure AI Search? 

 Azure AI Search (Foundry IQ) ist ein unternehmensweites Wissenssystem, das anspruchsvolle Retrieval Augmented Generation-Anwendungen (RAG) und Unternehmenssuchmaschinen unterstützt. Mit fortschrittlicher KI- und Suchtechnologie sowie Plattformintegrationen liefert es End-to-End-RAG-Systeme, die für App-Exzellenz, Enterprise-Readiness und schnelle Markteinführung entwickelt wurden. 

 02/ 

Welche Vorteile bietet Azure AI Search (Foundry IQ)? 

RAG-Exzellenz: Geben Sie den Maßstab für Anwendungsqualität mit der neuesten rigoros getesteten KI-Technologie vor, die vor Marktentwicklungen bereitgestellt wird. 
Geschwindigkeit: Entwickelt für die End-to-End-RAG-Entwicklung, gelangen Sie schnell von der Idee zur Produktion mit Integrationen und Funktionen über die gesamte Toolkette. 
Unternehmensniveau: Liefern Sie leistungsstarke RAG-Anwendungen, ohne Kompromisse bei Maßstab oder Kosten einzugehen. 

 03/ 

Was ist die Hybridsuche? 

 Die Hybridsuche führt eine Abfrage sowohl für die Textsuche (oder Schlüsselwortsuche) als auch für die Vektorsuche in einer Anforderung aus. Die Ergebnisse werden dann mit Reciprocal Rank Fusion (RRF) zusammengeführt. Die Hybridsuche ist für RAG-Szenarien nützlich: Die Vektorsuche ist effektiv bei der Suche nach Informationen aus Abfragen in natürlicher Sprache, und die Volltextsuche kann bestimmte Daten wie den Namen einer Person oder einen Produktcode finden. 

 04/ 

Was ist Retrieval Augmented Generation (RAG)? 

 RAG ist eine KI-Technik, die Suchtechniken mit generativen Modellen kombiniert, um präzise und kontextbezogene Antworten zu generieren. Sie ruft Informationen aus externen Quellen wie Datenbanken, Dokumenten oder dem Internet ab, um die Generierung von Ergebnissen zu verbessern. Dadurch wird sichergestellt, dass die von großen Sprachmodellen generierten Antworten korrekt und relevant sind und mit den aktuellsten Informationen angereichert werden. Weitere Informationen zu RAG und RAG in Foundry IQ.

 06/ 

Wo ist Azure AI Search (Foundry IQ) verfügbar? 

 Foundry IQ (Azure AI Search) ist weltweit in über 30 Ländern und Regionen verfügbar, und es werden regelmäßig neue Regionen hinzugefügt. 

 07/ 

Mit welchen Datenquellentypen ist Azure AI Search (Foundry IQ) kompatibel? 

Integrierte Indexer stehen für Azure Cosmos DB, Azure SQL-Datenbank, Azure Blob Storage und Microsoft SQL Server mit Hosting auf Azure-VMs zur Verfügung. Verwenden Sie die über 80 verfügbaren Connectors von Azure Data Factory oder Azure Logic Apps für die Herstellung von Verbindungen mit Ihren Datenquellen. Verschieben Sie Ihre Daten alternativ in einen Azure AI Search-Index. Dieser weist keine Einschränkungen für den Datenquellentyp auf. 

Azure AI Search unterstützt auch Datenverbindungen in Wissensdatenbanken, einschließlich SharePoint, dem öffentlichen Web und Azure Blob Storage. 

Lesen Sie die Dokumentation für die neuesten unterstützten Wissensquellen. 

Wissensquellen und Wissensdatenbanken sind im Microsoft Foundry-Portal und in Azure AI Search verfügbar. 

 08/ 

Welche Dateiformate können verwendet werden? 

 Microsoft Word, PowerPoint und Excel, Adobe PDF sowie PNG, RTF, JSON, HTML und XML werden unterstützt. 

 09/ 

Was ist der Unterschied zwischen der Azure AI Search (Foundry IQ) und Azure OpenAI? 

 Foundry IQ (Azure AI Search) und Azure OpenAI sind zwei verschiedene Dienste.

 Foundry IQ ist eine Wissensdatenbank und ein Abrufsystem, das für RAG- und Unternehmenssuchanwendungen entwickelt wurde. Azure OpenAI bietet KI-Modelle und Tools zur Entwicklung von Agenten für Unternehmensanwendungen.

 Beide werden zusammen für KI-Agenten verwendet, die auf private Unternehmensdaten zugreifen. 

 10/ 

Ist Azure AI Search (Foundry IQ) eine Vektordatenbank? 

Foundry IQ (Azure AI Search) unterstützt die Vektorsuche, die Stichwortsuche und die Hybridsuche, bei der Vektor- und Nicht-Vektorfelder im selben Suchkorpus kombiniert werden. Es speichert die Daten, die Sie abfragen, und fungiert so als Vektorspeicher für Anwendungen, die Langzeitspeicher, eine Wissensdatenbank oder Basisdaten für die RAG-Architektur (Retrieval-Augmented Generation) benötigen. Dadurch wird die Azure AI Search zu einem vielseitigen Tool, das bei Bedarf als Vektordatenbank verwendet werden kann. 

 11/ 

Welche Algorithmen verwendet Azure AI Search (Foundry IQ)? 

 Foundry IQ (Azure AI Search) verwendet fortschrittliche Algorithmen wie „Exhaustive k-nearest neighbors“ (KNN) und „Hierarchical Navigable Small World“ (HNSW) für die Suche nach ungefähren nächsten Nachbarn ( Approximate Nearest Neighbor, ANN), sodass Abfragen zur Vektorsimilarität semantisch ähnliche Informationen finden können. Es verwendet außerdem BM25-Relevanzbewertung für die Volltextsuche und berechnet Suchergebnisse anhand der Übereinstimmungsstärke. 

 12/ 

Unterstützt Azure AI Search die Indizierung von Daten aus mehreren Datenquellen? 

 Foundry IQ (Azure AI Search) unterstützt indizierte und Remotequellen über Wissensquellen. Mit einer Wissensdatenbank können Sie mehrere Quellen auswählen, die einbezogen werden sollen. Sie können auch mehrere Wissensquellen aus demselben Dienst hinzufügen (z. B. mehrere Suchindizes). 

 13/ 

Was ist der Unterschied zwischen Azure Cognitive Search und Azure AI Search (Foundry IQ)? 

Azure Cognitive Search heißt jetzt Foundry IQ (Azure AI Search). Alle vorhandenen Bereitstellungen, Konfigurationen und Integrationen funktionieren weiterhin wie zuvor. Es gibt keine Änderungen an den Preisen und keine Breaking Changes an APIs oder SDKs. 

 14/ 

Was ist der Unterschied zwischen Azure AI Search und Foundry IQ? 

 Foundry IQ ist Azure AI Search. Alle in Foundry IQ verfügbaren Funktionen sind in Azure AI Search verfügbar. Bestehende Kundschaft hat Zugriff auf alle neuesten Features und muss nicht zu einer neuen Oberfläche oder Erfahrung migrieren.
