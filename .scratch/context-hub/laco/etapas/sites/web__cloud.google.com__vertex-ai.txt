How much does Gemini platform cost?

The cost of the Gemini platform is usage-based and flexible, derived from the specific AI models deployed and infrastructure usage. For models, users pay based on token consumption through several payment tiers—including standard Pay-as-you-go (PayGo), discounted Flex PayGo for latency-tolerant jobs, and premium Priority PayGo for higher reliability—or via Provisioned Throughput subscriptions for predictable, guaranteed throughput. 
Additional infrastructure charges, with the exception of those not available through Gemini platform such as Model Armor or Observability, are metered via three unified dimensions: Agent Compute (vCPU), Agent Memory (RAM), and Agent Storage (GiB) (plus token pass-through). Because expenses vary heavily by model and scale, users should consult contact sales to get granular estimates or explore volume-based enterprise discounts.

How much does it cost to use Gemini platform for document retrieval?

Document retrieval on the Gemini platform is handled by Agent Search. The billing is primarily usage-based, calculated per 1,000 successful search queries alongside standard storage charges for indexed data (billed per GiB/month). Standard semantic or keyword-based document retrieval is billed at approximately $4.00 per 1,000 queries, covering tasks like scanning the index, returning document snippets, and querying enterprise connectors.

Does Google Cloud offer a free trial for the Gemini platform?

Yes, Google Cloud offers a free trial that applies directly to the Gemini platform, allowing new users to explore and build AI agents without financial commitment. Eligible new users receive a standard $300 Google Cloud free trial credit valid for 90 days, which can be applied directly toward Gemini platform usage, including agent runtime compute processing, active memory, and underlying generative model queries. In addition to this promotional welcome credit, the platform provides continuous monthly Free Tier allowances (per billing account, per month) for core infrastructure, covering the first 50 hours (180,000 vCPU-seconds) of compute, the first 100 hours (360,000 GiB-seconds) of RAM, and the first 1 gibibyte of storage for agent runtimes. This setup makes it easy for users to prototype agentic workflows, integrate private data stores, and launch pilot programs at no initial cost.
