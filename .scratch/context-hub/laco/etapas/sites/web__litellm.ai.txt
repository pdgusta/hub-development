Questions developers ask
Short answers. The docs have the detail.
What is LiteLLM?
LiteLLM is an open-source AI gateway (LLM proxy) that puts your entire AI stack behind one OpenAI-compatible API. It tracks and caps spend per key, team, and model, routes each request to the right model, and can be self-hosted anywhere, including fully air-gapped.Is LiteLLM free and open source?
Yes. The LiteLLM gateway is MIT-licensed and free to self-host. An Enterprise tier adds SSO, RBAC, audit logs, SCIM, and dedicated support on top of the same open-source core — not a different product.What is an AI gateway (LLM gateway)?
An AI gateway, also called an LLM gateway or LLM proxy, is a single control point in front of many LLM providers. It gives applications one API to call, and gives platform teams centralized cost tracking, budgets, routing, caching, and governance across every model.Can I self-host LiteLLM in an air-gapped environment?
Yes. LiteLLM self-hosts in your own cloud or a fully air-gapped environment and sends no telemetry to LiteLLM. Prompts go only to the model providers you configure. Deploy with an official Helm chart or Terraform module, on your own Postgres and Redis, scaling with Kubernetes autoscaling.How many LLM providers and models does LiteLLM support?
LiteLLM supports 140+ LLM providers and 1,892 models through one OpenAI-compatible interface, so you can add or swap models without changing application code.How does LiteLLM control LLM costs?
LiteLLM attributes every request automatically and gives each team a virtual key with a hard budget. When a key hits its cap, requests stop, so a runaway job or leaked key cannot quietly run up the bill. Spend can be exported to Prometheus, Datadog, or CloudZero for chargeback.
