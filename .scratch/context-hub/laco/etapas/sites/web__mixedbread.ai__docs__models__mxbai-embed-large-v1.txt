Find the maintained resources for earlier Mixedbread embedding and reranking models and migrate to current search workflows.

Mixedbread previously published standalone documentation for direct embedding
and reranking APIs and for each open-source model generation. Those reference
pages are no longer part of the current documentation, but the model artifacts
and their technical release posts remain available.

Current search workflowCopy Anchor Link

For new managed-search integrations, start with Stores.
Stores handle parsing, indexing, retrieval, and reranking as one workflow. See
Store search for retrieval options and
reranking for current model configuration.

If you maintain an integration with the earlier direct embedding or reranking
APIs and need migration help, contact support@mixedbread.com.
