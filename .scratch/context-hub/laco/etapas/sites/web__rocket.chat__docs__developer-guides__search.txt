Configure how users search for messages in workspace rooms. These settings apply only to Search messages within rooms. They do not affect the global spotlight search, which searches for users, channels, and rooms by name from the search bar at the top of the workspace.
To access this setting, navigate to Manage > Workspace > Settings > Search.

Search Provider: Select the backend provider used for message search. Default provider is the only option and it uses MongoDB's text index to search messages.
Default provider

Global search : When enabled, global search extends an in-room message search to cover every room the user is a member of, instead of limiting results to the current room. Users will have the option to enable it while searching for a text string in any room. It returns results for the matching string across all rooms that the user is a member of.

Page Size: The number of search results displayed per page.
The global search feature is currently in beta and may not function as expected.
