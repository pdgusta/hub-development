Get started Using the plugin

With the plugin installed, open it from the Plugins panel. Create or select a text layer in your artboard. This text will act as your base style. With a text layer selected, Typescale gives you a few options to configure:

Scale - This is the number by which your base font size is multiplied. Lower ratios will give subtle differences, while higher ratios will offer more dramatic variations.

Sizes - Here you specify how many sizes you require, above and below your base size.

Content - Option to replace your text with pre-set example text.
