TLDR¶

Install Piccolo:

pip install piccolo

Experiment with queries:

piccolo playground run

Give me an ASGI web app!

piccolo asgi new

FastAPI, Starlette, BlackSheep, Litestar, Ravyn, Lilya, Quart, Falcon and Sanic
are currently supported, with more coming soon.
