 The Showcase 

 Open source change data capture 
 Stream changes from your database. 
 Debezium is an open source distributed platform for change data capture. Start it up, point it at your databases, and your apps can start responding to all of the inserts, updates, and deletes that other apps commit to your databases. Debezium is durable and fast, so your apps can respond quickly and never miss an event, even when things go wrong.

Do more with your data 
React every time your data changes without modifying the apps that write it. Purge caches, update search indexes and keep other systems in sync. 

Simplify your apps 
Stop making one service update the database and the search index and the cache. Move that work into services that consume change events instead. 

Never miss a beat 
Take services down for maintenance and Debezium resumes exactly where it left off, in commit order, without dropping an event. 

React quickly 
Built for low latency and high throughput. Proven, scalable, and comfortable with large volumes of data. 

Install Debezium your way 
The same connectors, the same change events, several different runtimes. Pick the one that matches the infrastructure you already run. 
 Most popular 
Kafka Connect 
The classic distributed installation 
Run Debezium connectors inside a Kafka Connect cluster and stream change events straight into Apache Kafka topics. 
Horizontal scaling and automatic task rebalancing 
Offsets and schema history stored durably in Kafka 
Single Message Transforms and the full Connect ecosystem 
 Learn more Documentation 
Debezium Platform 
The managed way to run Debezium on Kubernetes 
A web front end over the Debezium Operator. Design a pipeline once, from source through transforms to destination, and the Platform deploys and manages it on your cluster. 
Design pipelines visually instead of hand-writing connector configuration 
Full lifecycle management - create, deploy, edit, pause, resume, monitor 
Backed by the Debezium Operator, so the cluster stays declarative 
 Learn more Documentation 
Debezium Server 
Standalone, no Kafka required 
A ready-to-run application that captures changes and sends them to a messaging infrastructure of your choice. 
Sinks to Kinesis, Pub/Sub, Pulsar, Redis, RabbitMQ, NATS and more 
Configured with a single properties file 
Small footprint, quick to stand up 
 Learn more Documentation 
Operator for Debezium Server 
Operator managed, cloud native 
Declare your pipelines as custom resources and let the Debezium Operator reconcile them the way Kubernetes reconciles everything else. 
GitOps friendly, fully declarative configuration 
Rolling upgrades and self healing handled for you 
Add Debezium Platform on top for a managed UI over the same Operator 
 Learn more Documentation

 Debezium & AI 
Give your models fresh context 
Retrieval pipelines and agents are only as current as the data behind them. Debezium turns every committed row change into an event, and can parse, vectorise and deliver it to a vector store without any glue code in between. Explore Debezium for AI

Embeddings in the pipeline 
The Embeddings transformation vectorises text as it passes through, using Ollama, Hugging Face, Voyage AI or a local ONNX model. 

Document parsing 
The Docling transformation converts PDF, DOCX and HTML into a form a language model can actually consume. 

Straight into a vector store 
Debezium Server writes to Qdrant and Milvus directly, so the vector index follows the database rather than a nightly job. 

Native vector columns 
Vector column types are captured with their semantics intact, and the Vector to JSON transformation remaps them when you need something plainer.
