How you can use RavenDB

Auto-optimized Fast Querying
Nobody likes slow queries. RavenDB automatically ensures every query is fast, no matter what criteria you use.

RQL

// a query using FirstName criterion
from "Employees" where FirstName == "Anne"

// a query using LastName criterion
from "Employees" where LastName == "Dodsworth"

// a grouping query
from "Employees"
group by Address.City
select Address.City, count()

Multi-Modal Search Infrastructure
Want to build a RAG system, support Full Text Search over large sets of data, or provide Spatial search capabilities? RavenDB has you covered.

Integrated Data Modeling
Model complex entities as they exist in the real world. Store core JSON data, large binary attachments, and high-frequency metrics in a single document boundary.

Universal Data Connectivity
Whether you're pulling data from Kafka, pushing updates to SQL, or consuming data via Data Subscriptions, RavenDB reliably handles your data as it moves across your entire stack.

Native AI Support
RavenDB provides the infrastructure for AI-native applications managing conversation histories, vector embeddings, and "AI Attachments" natively, reducing the latency and complexity of agentic systems.
