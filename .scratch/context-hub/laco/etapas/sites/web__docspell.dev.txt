5// Starts a Stripe Checkout session for upgrading to Pro.
6// Creates the Stripe customer on first checkout, so the
7// customer portal works later without a second one.
8export async function startCheckout(plan: "pro" | "team", interval: Interval) {
9 const user = await getDbUser()
10 if (plan === "team") return fail("Team is sales-only for now")
11
12 let customerId = user.stripeCustomerId
13 if (!customerId) customerId = await createCustomer(user)
14
15 const session = await stripe().checkout.sessions.create({
16 customer: customerId,
17 mode: "subscription",
18 line_items: [{ price: await priceIdFor(plan, interval), quantity: 1 }],
19 })
20 return { success: true, data: { url: session.url } }
21}

§3
Edit it, then ship it.
Every page is written from the files it describes and lands in a proper block editor. Fix a sentence, move a section, drop in a screenshot. Hit publish and it's a fast docs site with search.3

§4
Keep up when the code moves.
Docs go stale because nobody notices the code changed. DocSpell remembers which files each page came from, so when they change you can regenerate just that page instead of rewriting everything.4
4It compares each source file's git hash, one GitHub call per doc space, and lists the pages that drifted.

Which languages does it understand?+

Pretty much all of them. DocSpell reads your source as text, so TypeScript, Python, Go, Rust, whatever you've got. It does best when the code has sensible module boundaries and at least a short README.Copy link to this answerDoes DocSpell keep my source code?+

No. Files are pulled from GitHub while a generation runs and sent to the AI model to write the pages. We keep the pages it writes, not your code.Copy link to this answerWhat do I get on the free plan?+

One AI generation from your own repo, the full editor, and publishing with no time limit. The pricing table above always has the current limits.Copy link to this answerCan I edit what the AI writes?+

Yes, and you should. Every page lands in the editor as a normal page. Rewrite it, reorganise it, or delete it.Copy link to this answerWhat happens when my code changes?+

Each page remembers the files it was written from. When those change, you can regenerate that one page without touching the rest of your docs.Copy link to this answerCan I use my own domain?+

Yes, on paid plans. Add a CNAME pointing at DocSpell and we sort out the certificate.Copy link to this answerCan I cancel any time?+

Yes. Cancel from billing and you keep your plan until the end of the period you paid for. The refund policy has the details.Copy link to this answer
