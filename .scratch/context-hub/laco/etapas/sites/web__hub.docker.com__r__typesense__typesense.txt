typesense/typesense repository overview

Typesense offers a delightful, out-of-the-box search experience. From instant search, to autosuggest, to faceted search, to vector search and semantic search, Typesense has got you covered.

An open source Algolia alternative and an easier-to-use ElasticSearch alternative.
⁠Usage

On Docker, you can run Typesense like this:

export TYPESENSE_API_KEY=xyz

mkdir $(pwd)/typesense-data

docker run -p 8108:8108 -v$(pwd)/typesense-data:/data typesense/typesense:30.1 \
 --data-dir /data --api-key=$TYPESENSE_API_KEY --enable-cors
