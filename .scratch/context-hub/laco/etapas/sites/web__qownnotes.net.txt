Getting Started

Up and Running in Under 5 Minutes

QOwnNotes is designed for immediate productivity. Follow these steps to go from download to organized notes in minutes.

1

Download the Installer

Get the free installer for your platform — Windows, macOS, or Linux — from our download page. No account or email required.

2

Run the Installer

Double-click the installer and follow the setup wizard. Installation takes under two minutes on any modern computer.

3

Choose Your Notes Folder

Pick a local folder where your Markdown files will be stored. This can be a Nextcloud sync folder for automatic cloud backup.

4

Create Your First Note

Press Ctrl+N (or Cmd+N on Mac) to create a new note. Start typing in Markdown and watch the live preview update in real time.

5

Connect Nextcloud (Optional)

Go to Settings → Nextcloud, enter your server URL and app password to enable note versioning, trash, and todo sync.

6

Customize and Organize

Add tags, create subfolders, install scripts from the community repository, and choose your preferred theme. QOwnNotes adapts to your workflow.

FAQ

Frequently Asked Questions

Quick answers to the most common questions about QOwnNotes download, setup, and usage.

📋 General Questions

Is QOwnNotes really free? 
+

Yes, QOwnNotes is completely free and open-source. There is no paid tier, no premium plan, and no subscription. Every feature is available to every user at no cost, forever. The application is released under the GNU GPL v2 license.

Where are my notes stored? 
+

Your notes are stored as plain Markdown .md files on your local file system in any folder you choose. QOwnNotes does not use a proprietary database. You can open, edit, move, and back up your notes with any text editor or file manager at any time.

Does QOwnNotes require an internet connection? 
+

No. QOwnNotes works entirely offline for note creation, editing, search, and organization. An internet connection is only needed if you configure Nextcloud sync, and even then, notes are still accessible offline through the local Nextcloud sync folder.

Can I use QOwnNotes without Nextcloud? 
+

Absolutely. Nextcloud integration is optional. QOwnNotes works perfectly as a standalone local note app without any cloud connection. You can add Nextcloud later at any time without affecting your existing notes.

Is QOwnNotes available in my language? 
+

QOwnNotes is translated into over 60 languages by the community through Crowdin. The application automatically uses your system language if a translation is available. You can also manually select a language in the settings.

⚙️ Technical Questions

How do I sync QOwnNotes across devices? 
+

Install the Nextcloud Desktop Client on each computer, sync your notes folder, and configure QOwnNotes to use that folder on each device. Install the QOwnNotesAPI Nextcloud app for version history, trash, and todo sync. Changes propagate automatically when the Nextcloud client is running.

Can I access QOwnNotes notes on Android? 
+

QOwnNotes does not have a native Android app, but your notes are accessible on Android through Nextcloud sync combined with a Markdown editor like Markor. The Nextcloud Notes Android app also works well for basic access and editing.

How do I install QOwnNotes on Arch Linux? 
+

Use an AUR helper: yay -S qownnotes or paru -S qownnotes. Alternatively, install via Flatpak from Flathub: flatpak install flathub net.pbek.QOwnNotes. The AUR package is updated promptly after each upstream release.

What is the scripting engine in QOwnNotes? 
+

QOwnNotes includes a JavaScript scripting engine that lets you automate tasks, create custom note templates, modify the interface, process notes programmatically, and integrate with external services. Scripts are available from a community repository inside the application.

How do I encrypt notes in QOwnNotes? 
+

Select any note, then use Edit → Encrypt note. You will be prompted to set a passphrase for that note. The note is then stored in an encrypted format. You will need to enter the passphrase each time you open the encrypted note. Individual notes can have different passphrases.
