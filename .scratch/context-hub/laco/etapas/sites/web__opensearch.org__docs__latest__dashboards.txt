OpenSearch Dashboards 
OpenSearch Dashboards is the web UI for OpenSearch. Use it to search and explore your data, build visualizations and dashboards, and manage your cluster without writing API requests. 

Install OpenSearch Dashboards 
Install OpenSearch Dashboards using Docker, Helm, a package manager, a tarball, or on Windows 

Try it in the Playground 
Explore OpenSearch Dashboards in your browser without installing anything 
Getting started 

Getting started 
Learn the main applications step by step using sample data 

Navigating OpenSearch Dashboards 
Learn the layout of the home page and the left navigation panel 
Adding data 
To work with data in OpenSearch Dashboards, either add it to OpenSearch or connect to where it’s stored: 
Ingest data into OpenSearch indexes. 
Connect data sources, such as other OpenSearch clusters, Amazon S3, or Prometheus, to query data without ingesting it. 
Exploring and visualizing data 
Use the following applications to search your data and present it visually. The table lists the query language that you use in each application. 

 Application Use it to Query language 
 Discover Search, filter, and examine your data. DQL or query string (Lucene) 
 Visualize Create charts, maps, tables, and other visualizations using a point-and-click interface. DQL or query string (Lucene) 
 Dashboards Combine multiple visualizations into a single page and filter all of them at once. DQL or query string (Lucene) 
 Query Workbench Run on-demand SQL and PPL queries. SQL or PPL 
 Dev Tools Send OpenSearch API requests from the browser. Query DSL 
If workspaces are enabled, you can also create visualizations by writing PPL or PromQL queries. For more information, see Creating visualizations using queries. 
Managing indexes and snapshots 
Use the following applications to manage indexes and snapshots. 

 Application Use it to 
 Index Management Manage indexes, data streams, aliases, templates, and Index State Management policies. 
 Snapshot Management Back up and restore your cluster’s indexes and state. 
Observability 
To monitor logs, traces, and metrics in OpenSearch Dashboards, see Observability. To set up prebuilt dashboards and visualizations for common data sources, such as NGINX logs, see Integrations. 
Using AI assistance 
The OpenSearch Assistant adds AI-powered assistance to OpenSearch Dashboards. 
Configuring and administering OpenSearch Dashboards 
You can configure OpenSearch Dashboards in two places, depending on your role. 

 Where Who uses it What you can configure 
 Dashboards Management, an application in the UI Users who have the required permissions Index patterns, data sources, saved objects, and advanced settings 
 The opensearch_dashboards.yml configuration file Administrators who deploy OpenSearch Dashboards and have access to the host Deployment-level settings, such as custom branding, network compression, and workspaces. For more information, see Settings and administration and Configuring OpenSearch Dashboards.
